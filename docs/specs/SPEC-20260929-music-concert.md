# SPEC-20260929：音乐夜场演唱会

- 状态：已完成
- 提出日期：2026-09-29
- 相关迭代：`docs/iterations/ITER-20260929-music-concert-01.md`

## 背景与目标

用户在讨论音乐场景后明确要求开始尝试第一版夜场演唱会。现有 `ImmersiveStage.tsx` 提供封面、歌词和频谱，`usePlayer.ts` 已暴露 AnalyserNode。本轮在音乐播放页增加可进入、退出的演唱会视图，展示大屏歌词、随音频变化的灯光、观众席荧光棒和前排/看台/全景三个固定机位。

## 非目标与不修改边界

不做混响、EQ、音频处理、自动副歌识别、手动演出编排、环境场景、云端功能。保持原播放器、歌词解析/偏移、原声、音量、切歌、导入下载、持久化、桌面外壳和 Service Worker 不变。不增加校验、兜底、重试、迁移或外部资源。

## 方案与状态

- 播放页提供“夜场演唱会 / 返回歌词”切换，原播放栏持续可用。
- 新组件使用 CSS 舞台、灯架、光束、大屏和观众席；读取现有 analyser 驱动低频与高频视觉强度。
- 大屏展示当前逐字/逐行歌词；没有活动歌词的时间段展示歌曲标题，不虚构演唱进度。现有纯文本歌词仍在原歌词视图阅读。
- 三个机位改变场景透视与距离，不改变播放时间或声音。
- 暂停时停止动态灯光与荧光棒运动；退出时释放动画循环；减少动态效果偏好下展示静态舞台。
- 状态属于音乐组件，仅保留在本次窗口生命周期，无持久化或数据迁移。

## 平台影响

仅音乐应用内部视图与样式。不涉及应用注册、窗口生命周期、跨应用事件、存储/备份/清理、资源包、离线协议或部署。复用音乐应用按需加载；无需新增素材与依赖。

## 修改范围

- `src/apps/music/entry.tsx`：舞台入口和视图选择。
- `src/apps/music/ConcertStage.tsx`、`concert.css`：舞台和音频视觉响应。
- `tests/unit/musicConcert.test.ts`：歌词呈现与频段响应验证。
- 本 Spec 与迭代记录。

## 验收标准

- [x] AC-1：播放歌曲时能进入夜场、切换三个机位并返回歌词，播放连续。
- [x] AC-2：舞台大屏跟随既有歌词时间，包括逐字进度、间奏及无歌词曲目标题展示。
- [x] AC-3：光束和观众荧光棒响应音频；暂停、退出和减少动态效果偏好停止连续视觉动画。播放/暂停已实测，退出清理与减少动态效果路径经代码审查。
- [x] AC-4：窄窗口可操作机位和播放栏；不新增网络请求和存储。

## 验证计划

TypeScript 检查、音乐相关单测、浏览器一个最短播放路径（含机位、暂停、窄窗口）。不运行 lint 和完整构建。

## 风险与后续

灯光只响应频谱，不声称识别乐器或副歌。视觉规模需兼顾小窗口。音效、演出编排与更多场景留待后续明确选择，不在本轮实现。无迁移，可移除舞台入口及组件回滚。

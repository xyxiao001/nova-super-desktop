## 背景

首关此前已接入原版地图、Spine、波次、领主移动、拖动合成及简化攻击。本轮把战斗推进为 Core 统一结算：闪电丘释放帧直连，暴走萌弹双弹推进与碰撞，小丑皇投弹、毒区与周期伤害，精灵大师召唤物出生、寻敌、移动和扇形攻击，以及沙王移动、射程和双段近战均已接入。

原版两段 WASM 能编译，但框架启动被微信 SDK 依赖阻断，尚未进入实例化和场景。本阶段采用“读取原版 Lua、配置和资源，移植已证实行为，再与实机对照”的路线。完整微信运行时移植不作为本阶段前置条件。

本 Spec 是下一阶段的有限执行范围，不启动上位规划中的自动逐关扩展。历史实机记录按时间追加，其中早期的“合成手势未知”和“固定教学召唤”已被后续证据及提交取代。

## 目标

在首关完成四名出战英雄与沙王的基础攻击闭环：索敌 → 起手 → 发射或效果生成 → 命中 → 伤害/状态结算 → 收招及下一次攻击。每个环节有可追溯依据和独立验收结果，明确区分动画事件、投射物命中、技能等待时间与冷却。

先完成闪电丘的闭环，作为首个可对照交付，再逐个接入暴走萌弹、小丑皇、精灵大师和沙王。每个执行回合只处理一个明确问题；上一项通过后进入下一项。

上述数值描述提交基线，不代表所有数值均已通过实机验收。具体注意：

- 属性5以毫米表示；当前投影每世界单位100逻辑像素。基础属性、最终有效射程和屏幕范围圈必须分开记录。
- Spine `attack_1` 时长不必然等于 `Skill.WaitTime` 或冷却；事件可能仅播放音效或生成弹体。
- 闪电连锁的额外2个目标、75%伤害有实机技能说明；现用最近目标逐跳搜索仍待确认。
- 原弹体 `destroyDelayTime=0.15` 不证明飞行耗时为0.15秒，也不证明所有连线持续0.15秒。
- 小丑皇直接伤害系数0不能据此改成任意非零值；精灵大师统计为0不能据此认定召唤物无伤害。
- 合成同类同阶后从出战池随机变成高一阶英雄、四阶上限及职业升阶攻击倍率已接入；随机池保持当前四名出战英雄，未额外推断隐藏权重。

## 技术方案

### 配置与提取

- 在现有提取器和关卡 Manifest 中按证据补充攻击需要的字段，运行时消费单一数据来源。不要另建一套与 Manifest 漂移的技能常量表。
- 分别表达有证据的发射事件、命中机制、技能锁定时长、冷却及特效寿命；不把这些概念继续全部塞进 `hitTimeSeconds`。
- 字段的具体结构由首个已证实攻击样本决定，只添加当前技能实际需要的数据，不预建全部技能系统。
- 修改提取数据时同步对应类型、正式产物及直接相关资源契约测试。无需为未变化的资源重新生成全包。

### 模拟与表现

- `frontlineCore.ts` 保有战斗结果的唯一决定权；动画播放或渲染回调不再次扣血。
- 若已确认存在飞行过程，则在 `BattleState` 中记录其发射和在途状态，按模拟时间推进，到达时按原规则命中；具体跟踪/落点/目标死亡规则先取证。
- `BattleCanvas.tsx` 使用模拟中的同一攻击时间线播放 Spine、弹体和命中特效，避免渲染帧率改变命中顺序。
- 原资源中已有的相关贴图、骨骼、音效和可提取特效参数优先复用；Unity特效需移植表现，不能把临时直线命中提示当作最终效果。
- 毒区及召唤物仅在各自迭代增加所需状态；它们的伤害和击杀归属接入现有结算，不额外发放奖励。
- 暂停冻结所有新增模拟与表现时间；倍速按既有模拟比例推进。关闭窗口继续遵守现有应用生命周期。

### 状态归属

战斗状态留在游戏内部，配置随打开游戏按需加载。投射物、毒区、召唤物和攻击事件是单局临时状态；不新增存档字段、IndexedDB、localStorage、云端数据或迁移。

## 验证计划

每次代码改动完成后运行一次：

```sh
npx tsc --noEmit --incremental false
npx vitest run tests/unit/frontlineCore.test.ts tests/unit/frontlineLevel.test.ts
```

只有资源或Manifest变更才追加 `tests/unit/frontlineLevelAssetManifest.test.ts`。单测围绕真实行为风险：发射前不命中、在途目标变化、重复结算、时间推进、状态到期及技能特定边界。原版尚未确定的边界先取证，不用测试固化猜测。

浏览器每项走一条最短路径：本地战斗入口 → 首关 → 对应英雄及台座 → 目标事件 → 暂停采样。优先现有入口和测试夹具；测试中固定阵容/随机值不得改变生产召唤规则。A7再做一次组合通关，不为每个小修反复全关操作。

保存对齐时间基准的原版/本地片段和必要叠图，列出起手、发射、命中的误差。人工操作参考客户端与自动操作混入同一片段时单独标记，不能误记为脚本输入。

文档改动只检查内容与链接，不运行代码测试。禁止默认运行lint、完整构建、全量测试和无明确问题的重复回归。检查目标diff并排除临时录像、浏览器测试目录、覆盖率和tsbuildinfo等产物；必要证据按清单保存，不批量提交缓存。

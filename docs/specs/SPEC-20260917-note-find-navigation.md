# SPEC-20260917：记事本文稿内查找导航

- 状态：已完成
- 提出日期：2026-09-17
- 相关 ADR：无
- 相关迭代：`docs/iterations/ITER-20260917-note-find-navigation-01.md`

## 背景与目标

全局搜索已能把用户带到文稿首个正文命中，但进入文稿后无法查看同一查询的其他命中。目标是在当前记事本窗口增加文稿内查找条，支持精确、不区分大小写的上一处／下一处循环导航，并让全局搜索定位自然衔接该查找条。

## 非目标与边界

- 不实现替换、正则、模糊搜索、搜索历史、全局索引或后台 Worker。
- 不修改记事本侧栏的文稿筛选能力。
- 不修改文件正文、存储、备份、Markdown 解析或阅读摘录来源。
- 不跨文稿自动跳转；每个记事本窗口维护自己的临时查找状态。
- 不新增快捷键冲突：仅当键盘事件发生在当前记事本窗口内时接管 Command/Ctrl + F。
- 不构建、提交、推送或发布。

## 用户可感知行为

- 点击“在当前文稿中查找”或在当前窗口按 Command/Ctrl + F 打开查找条。
- 输入查询后显示“当前序号 / 总数”；Enter 下一处，Shift + Enter 上一处，按钮同样可操作。
- 导航在首尾循环，精确选中正文匹配并滚动到近似位置。
- 全局搜索正文命中打开文稿时，自动打开查找条并显示该查询及首个命中。
- 文稿切换后关闭并清空当前窗口查找状态；Esc 关闭查找条但不修改正文。
- 预览模式发起查找或接收全局定位时切回编辑模式。

## 验收标准

- [x] 所有不重叠、大小写不敏感的精确匹配范围可复算，空查询返回空集合。
- [x] 上一处／下一处在首尾循环，零命中时无定位动作。
- [x] 查找条显示查询和命中计数，键盘与按钮均可导航。
- [x] 全局搜索传入的首个命中能够初始化文稿内查找状态。
- [x] 切换文稿、关闭查找条、Markdown 预览和保存状态保持正确。
- [x] TypeScript、相关单测、浏览器关键路径和 diff 审查通过。

## 确认记录

- 2026-09-17：用户连续授权推进下一项有限迭代；本轮选择与全局搜索直达直接相邻的文稿内导航。

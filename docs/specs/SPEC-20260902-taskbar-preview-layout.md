# SPEC-20260902：任务栏多实例预览布局收口

- 状态：已完成
- 提出日期：2026-09-02
- 负责人：Codex
- 相关 ADR：无
- 相关迭代：`docs/iterations/ITER-20260902-taskbar-preview-layout-01.md`

## 背景

窗口实例化完成后，任务栏可以按应用分组展示多个窗口，但预览面板仍由内容自然撑宽并相对任务栏入口居中。入口靠近屏幕边缘时面板可能越界，实例较多时最大宽度会切在半个预览项上，横向浏览也缺少稳定的尺寸约束。

## 目标

让任务栏多实例预览以完整预览项为单位确定尺寸，在左右屏幕边缘内稳定定位，并在实例超过可见容量时提供明确、不会影响最小化真实预览的横向滚动。

## 非目标

- 不实现非最小化窗口的真实快照；
- 不引入应用级 Preview 契约；
- 不保存实例级窗口几何；
- 不调整任务栏分组、右键菜单或 `Alt + Tab` 的业务行为；
- 不改变移动端任务栏隐藏策略。

## 方案

### 用户可感知行为

- 预览面板优先围绕对应任务栏入口居中；
- 面板始终保留 8px 视口边距，不超出左右屏幕边缘；
- 一次最多完整显示 4 个实例，更多实例通过横向滚动查看；
- 滚动以完整预览项为吸附单位；
- 最小化窗口的真实预览在面板滚动和重定位后仍与目标预览项对齐。

### 技术设计

- 在 `DesktopTaskbar.tsx` 提供纯布局函数，根据入口位置、实例数和视口宽度计算面板左边界、宽度及是否可滚动；
- 预览面板继续保留在对应 `.taskbar-entry` 内，通过相对偏移应用计算后的视口位置；
- 保持 `data-window-preview-target` 和 `.taskbar-preview` 滚动容器不变，并让 `WindowFrame` 同时观察目标项和预览容器尺寸；
- CSS 固定预览项尺寸，增加横向滚动吸附和窄滚动条。

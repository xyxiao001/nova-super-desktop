# SPEC-20260917：记事本安全 Markdown 预览

- 状态：已完成
- 提出日期：2026-09-17
- 相关 ADR：无
- 相关迭代：`docs/iterations/ITER-20260917-note-markdown-preview-01.md`

## 背景与目标

记事本当前只显示纯文本，阅读摘录和长文整理缺少结构化阅读视图。本迭代在同一份桌面文本上增加编辑／预览切换，支持常用 Markdown 阅读结构，并确保预览不执行用户 HTML、不加载 Markdown 图片。

## 非目标与不修改边界

- 不新增富文本、HTML 文件类型、第二套正文、格式迁移或自动改写。
- 不实现所见即所得、表格、脚注、公式、目录、语法高亮或 Markdown 导出。
- 不加载 Markdown 图片，不执行原始 HTML，不支持 `javascript:` 或 `data:` 链接。
- 不改变搜索、保存、摘录回链、文件复制、备份和窗口生命周期。
- 不引入第三方解析器，不新增网络资源或后台任务。
- 不构建、提交、推送或发布。

## 用户可感知行为

- 每个打开文稿可在“编辑”和“预览”间切换；新打开或搜索定位文稿时回到编辑视图。
- 预览支持标题、段落、粗体、斜体、删除线、行内代码、代码块、引用、有序／无序／任务列表、分隔线和安全链接。
- 原始 HTML 显示为普通文字；Markdown 图片显示为“图片已阻止加载”占位，不请求网络。
- 视图切换不修改正文；保存状态仍由原文本写入结果决定。

## 验收标准

- [x] 常用块级和行内语法正确形成结构化预览。
- [x] 原始 HTML 不执行，危险链接不生成链接，图片不产生网络资源节点。
- [x] 预览切回编辑后原文完全不变。
- [x] 普通文稿、阅读摘录、保存状态和搜索定位保持可用。
- [x] TypeScript、相关单测、浏览器关键路径和 diff 检查通过。

## 风险

这是有意受限的 Markdown 子集，不承诺与 GitHub Flavored Markdown 完全一致；无法识别的文本保持可读原文，而不是猜测或执行。

## 怪物生命

`MonsterLevelProp_C.lHP` 是 int64 池索引，`EctypeWave.monsterPropRatios`
是 list 池索引。生命计算为：

```text
absoluteHp = levelBaseHp * waveHpRatio
waveHpRatio = monsterPropRatios[propertyId=2] / 10000
```

六波生命倍率依次为 `1.00 / 1.20 / 1.80 / 2.34 / 2.34 / 2.38`。
`Monster.lHP_Count` 是血条分段数，不能作为生命倍率。

| ID | 名称 | 基础生命 | 血条分段 | 移速 |
|---:|---|---:|---:|---:|
| 1001 | 沙漠蜥蜴 | 299 | 1 | 400 |
| 1002 | 野狗 | 224 | 1 | 600 |
| 1003 | 沙甲虫 | 598 | 1 | 400 |
| 3001 | 沙漠蜥蜴精英 | 2392 | 5 | 320 |

第五波精英蜥蜴绝对生命为 `2392 * 2.34 = 5597.28`。

## 战斗经济

- 初始银币：100；
- 水晶生命：20；
- 召唤费用前七档：`10 / 20 / 30 / 45 / 60 / 80 / 90`；
- 强化费用前五档：`100 / 200 / 300 / 400 / 600`；
- 第 5 次召唤后开放强化。

每个刷怪组的 `coin` 与 `lExp` 已保留在生成配置中。当前模拟按单只怪物死亡
发放该组 `coin`；该归因仍需与参考客户端的逐杀金币变化交叉验证。

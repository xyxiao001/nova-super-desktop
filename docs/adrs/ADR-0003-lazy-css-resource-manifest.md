# ADR-0003：应用样式随模块加载，资源包由 Manifest 生成

- 状态：已接受
- 日期：2026-08-28
- 关联 Spec：`docs/specs/SPEC-20260828-p2-css-resource-packages.md`

## 背景

桌面外壳与全部应用共享一个全局样式入口，资源包展示与匹配规则也存在两个维护源。

## 决策

外壳只同步加载外壳 CSS；应用 CSS 由对应动态模块导入。资源包的展示字段、匹配字段和应用关联统一放在 App Manifest 模块，构建前生成 Service Worker 可执行配置。

## 影响

- 首屏不再主动包含阅读器及应用主体样式；
- 新增专属资源包只修改 Manifest 声明并重新生成配置；
- 生成文件必须提交，并由测试审计是否与 Manifest 一致；
- Service Worker 仍使用现有缓存策略和生命周期。

## 不包含

- 不拆成远程微前端；
- 不在运行时拉取配置；
- 不改变资源包 ID、缓存策略或更新协议。

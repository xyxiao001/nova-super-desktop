# ADR-0009：音乐续听位置归属音乐存储

- 状态：已接受
- 日期：2026-09-29
- 对应 Spec：`docs/specs/SPEC-20260929-music-resume.md`

## 决策

续听是音乐应用自己的状态，保存在现有 IndexedDB `nova-music/settings` 的可选 `playback` 键。记录歌曲 ID、秒数和队列引用，不复制音频，不放入桌面外壳或听歌时长统计。

位置与偏好分别写入，避免媒体事件提交位置时覆盖用户刚修改的音量或歌单。备份、恢复、删除歌曲、音频去重和清理沿用音乐存储生命周期。

媒体事件提供位置提交时机；没有新增计时器、后台任务或自动重试。打开应用只呈现续听入口，明确点击才恢复播放。旧数据没有记录时不显示入口，无数据库升级或历史回填。

## 影响

关闭和刷新后可以继续听；浏览器被强制终止时，尚未完成的异步写入无法保证保存。舞台、音效和演出流程不在本轮恢复范围内。

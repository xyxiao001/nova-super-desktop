# ADR-0005：暂缓多窗口实例与外部大型资源托管

- 状态：已接受
- 日期：2026-08-28
- 关联 Spec：`docs/specs/SPEC-20260828-p3-product-scaling-decision.md`

## 决策

NOVA 当前保持每应用单窗口实例，并继续同源托管大型资源。P2 的 Window reducer、App Runtime、Manifest 资源关联和独立 Cache Storage 已建立未来演进边界，但不提前改变产品能力。

## 原因

多实例会改变窗口、Dock、应用状态和文件编辑语义，当前没有明确用户场景；外部资源托管会引入远端依赖和跨域离线策略，而现有 85 MB 魔塔、27 MB 书籍等资源已经按需加载且不进入启动壳。

## 后续方案边界

若触发重新决策，多实例必须引入实例级身份与生命周期设计；外部托管必须另行 Spec 化资源版本、完整性、跨域缓存、离线恢复和发布回滚。本 ADR 不授权这些实现。

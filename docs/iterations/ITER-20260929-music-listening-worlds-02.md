# ITER-20260929：音乐场景、分享与布局

- 需求：用户授权分享舞台并继续听歌场景、声音和歌单演出；后续明确删除导演台、优化整体页面布局。
- 方案：继续使用音乐窗口与现有本地存储。分享扩展视觉配置，音效仅在窗口会话中主动开启。后续收拢舞台控制、移除时间事件与重演，不改导入、曲库下载或桌面窗口行为。

## 结果

1. 歌曲舞台链接携带场景、机位和灯色，公共曲库歌曲可分享。普通歌曲链接不变；不上传私人音频。
2. 六种听歌场景：夜场、列车、雨天房间、天台、黑胶、宇宙；使用已有歌词时序和真实音频频谱驱动视觉，支持暂停及减少动态效果。
3. 原声、Livehouse、音乐厅、复古电台、深夜聆听及独立雨声。只有主动选用才接入处理，恢复原声旁路处理。
4. 歌单演出支持名称、顺序、开场/主场/安可、开场和谢幕字幕、连续/留白/淡入淡出衔接、票根写入桌面图片。
5. 删除导演台、时间标记、事件特效与编排播放逻辑；不主动迁移或删除已有用户数据，旧事件不参与播放及新链接。
6. 舞台整体统一深色，精简侧栏和重复信息；舞台自适应高度，场景/机位同排，氛围设置浮层，播放器固定底部。窄屏保留横向导航与紧凑控制栏。

# ITER-20260903：宠物边缘拖拽与本地系统命令

- 状态：已完成
- 所属 Spec：`docs/specs/SPEC-20260903-desktop-pet-system.md`
- 对应验收项：AC-3、AC-14、AC-15
- 开始日期：2026-09-03
- 完成日期：2026-09-03

## 本轮目标

修复宠物无法拖到桌面最右侧的问题，并让明确的基础操作不依赖 AI：用户提交“我想玩五子棋”“我想看书”“打开系统设置”等命令后，直接打开对应本地应用。

## 本轮不做

- 不允许 AI 返回内容直接调用应用；
- 不执行删除、覆盖、清空、发送等高风险系统操作；
- 不把模糊关键词或普通讨论当作命令；
- 不修改窗口管理、应用注册和懒加载契约；
- 不启动开发服务器，不运行 lint 或完整构建。

## 实现内容

- 新增按宠物实际宽度计算的横向位置约束，替换固定 `17%–83%` 范围；
- CSS 与指针拖拽共享同一个水平安全边距，桌面变宽时仍可贴近左右边缘；
- 靠近边缘时闲逛只向桌面内侧移动；
- 建立 `PET_SYSTEM_COMMANDS` 本地命令注册表，覆盖主要应用与具体游戏；
- 命令注册表独立位于 `app/petSystemCommands.ts`，不与 AI 适配器或聊天兜底耦合；
- 具体游戏优先于游戏大厅，明确命令标记为 `immediate`；
- 对话提交后先执行本地命令，再考虑 AI；建议按钮和快捷按钮仍沿用显式点击。

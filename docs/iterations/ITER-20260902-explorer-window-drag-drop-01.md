# ITER-20260902：资源管理器跨窗口拖放

- 状态：已完成
- 所属 Spec：`docs/specs/SPEC-20260902-explorer-window-drag-drop.md`
- 对应验收项：AC-1 至 AC-6
- 开始日期：2026-09-02
- 完成日期：2026-09-02

## 本轮目标

让两个资源管理器窗口通过共享拖放协议完成文件和文件夹的移动或复制，并复用现有冲突处理与撤销链路。

## 本轮不做

- 不扩展到资源管理器之外的应用或任务栏；
- 不新增移动端拖放；
- 不修改文件模型、持久化格式或窗口实例模型；
- 不重做冲突弹窗和撤销 UI。

## 计划修改

- `app/desktopFiles.ts`：增加共享拖放载荷与操作模式函数；
- `src/apps/explorer/entry.tsx`：接入共享函数；
- `src/shell/DesktopRoot.tsx`、`src/shell/DesktopIcons.tsx`：统一桌面落点的拖放语义；
- `tests/unit/desktopFiles.test.ts`：增加协议与修饰键测试；
- `README.md`：补充跨窗口拖放说明。

## 实现假设

多个资源管理器实例共享 Workspace Runtime 和浏览器原生 `DataTransfer`。统一载荷读写与操作模式后，现有 `performFileOperation` 可以直接承担跨实例移动、复制、冲突处理和撤销，不需要增加窗口间状态。

## 实现—验证记录

### 第 1 轮

- 实现：在 `desktopFiles.ts` 集中拖放类型识别、载荷读写和复制修饰键判断；桌面与资源管理器统一接入该协议，并增加 `Option` 复制语义；
- 验证：执行 TypeScript、4 个相关测试文件共 33 项测试；在两个左右贴靠的资源管理器窗口间验证空白区域移动、拖入子文件夹、同名冲突“保留两份”和撤销；
- 结果：全部通过，浏览器控制台无运行时错误。

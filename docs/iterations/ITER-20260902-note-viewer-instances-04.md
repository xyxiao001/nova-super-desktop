# ITER-20260902：文稿与图片按资源实例化

- 完成日期：2026-09-02

## 本轮目标

开放记事本和照片查看器按桌面资源实例化，移除全局当前文稿与当前图片状态，并确保应用内切换资源时遵循复用当前实例或聚焦已有实例的规则。

## 本轮不做

- 不开放照片实验室、阅读器或游戏多实例；
- 不让内置精选照片进入桌面文件模型；
- 不允许同一文稿或桌面图片存在两个相同应用实例；
- 不实现跨窗口拖放或会话恢复；
- 不修改备份、资源缓存或 Service Worker。

## 计划修改

- `src/platform/apps/appManifest.ts`：启用记事本和照片查看器 `per-resource` 策略；
- `src/platform/windows/WindowRuntime.tsx`：增加实例级 active 查询；
- `src/platform/workspace/WorkspaceRuntime.tsx`：移除当前文稿、图片和对应选择命令；
- `src/shell/DesktopRoot.tsx`：按实例目标打开、创建和删除文稿与图片；
- `src/apps/notes/entry.tsx`：从实例目标读取文稿并处理实例内切换；
- `src/apps/viewer/entry.tsx`：从实例目标读取桌面图片并保留内置图库本地状态；
- `tests/unit/`：补充策略、实例上下文和架构契约测试。

## 实现假设

桌面文稿和图片继续只存储在 `DesktopItem[]` 中，窗口实例仅保存资源 ID。记事本新建文稿时绑定发起实例；其他入口打开资源时按 `app + target` 去重。

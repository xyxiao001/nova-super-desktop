## 目标与范围

在现有音乐播放页增加夜场演唱会视图。修改范围按 Spec；不改播放器声音、持久化、下载和桌面外壳，不实现后续演出编排与场馆音效。

## 实现假设

现有 analyser 和逐字歌词足以支持 CSS 舞台、大屏字幕和三机位视觉，不需要新增引擎或音频处理。

## 实现—验证记录

### 第 1 轮

- 完成舞台入口、CSS 舞台、灯架/光束/观众席、大屏逐字歌词及三个固定机位。仅采样已有 analyser，不改音频链路。
- `npx tsc --noEmit --incremental false` 通过；关闭增量输出以免产生 tsbuildinfo。
- 音乐存储、频谱/听歌记录、移动播放相关 28 项既有测试通过；新舞台 5 项测试中 1 项最初失败：测试错误地假定增强 LRC 的最后一个字结束等于整句结束。

### 第 2 轮

- 只修正测试夹具，改用现有解析器明确支持行结束时间的 YRC；未修改产品歌词解析逻辑。
- 新舞台 5 项测试全部通过，共 33 项相关测试通过。
- 使用本地音乐 App 的现有目录播放《可爱女人》，验证进入舞台、前排/看台/全景、返回原歌词；播放时间持续前进。
- 实际 analyser 采样得到低频 0.914、高频 0.516 等变化；暂停后 data-playing=false、视觉频段值归零、荧光棒 animation-play-state=paused。
- 检查 1280px 桌面及 390px 窄屏；窄屏舞台 clientWidth=scrollWidth=388px，三个机位均在视口内，播放栏可用。
- 减少动态效果通过 matchMedia 分支与 CSS 静态审查，未更改用户系统设置；卸载清理通过 effect cleanup 审查。

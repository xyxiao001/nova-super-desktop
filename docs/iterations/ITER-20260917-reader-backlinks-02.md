# ITER-20260917：阅读摘录回链

- 状态：已完成
- 所属 Spec：`docs/specs/SPEC-20260917-reliable-notes-and-reading.md`
- 对应验收项：AC-4、AC-5、AC-6、AC-7
- 开始日期：2026-09-17
- 完成日期：2026-09-17

## 本轮目标

新建摘录保存本地书籍版本和选区起点，记事本可以返回原文；失效来源不猜测位置，普通文稿与旧摘录保持不变。

## 本轮不做

不历史回填、不自动下载、不建立关系库、不改变备份版本、不实现搜索直达、Markdown、工作集或 AI 写作。

## 实现—验证记录

- 新增可选 `readerSource`，正文仍是原 `DesktopItem` 文本；元数据随既有文件存储、复制、备份、恢复和清理。
- 阅读器从真实 DOM 选区计算章节、段落和字符偏移；普通滚动与仿真翻页均为段落添加定位标记。
- 回链打开本地书籍、校验书籍版本和位置，并切换到可确定定位的滚动阅读；失效时显示提示，不覆盖文稿。
- 记事本只为带来源的摘录显示来源条和“返回原文”。
- Stabilize LaunchRuntime 的确认回调，避免工作区保存状态刷新干扰异步启动流程。
- 新增 ADR-0008，记录来源跟随文件保存且不升级数据库/备份版本的长期边界。

## 验证结果

- `npx tsc --noEmit --incremental false`：通过。
- 相关单测：10 个文件、75 项测试全部通过；补充来源 UI 用例后单独复验。
- 浏览器最短路径：在 `127.0.0.1` 隔离来源中创建文稿并看到“保存中…”→“已保存到本机”；导入固定 TXT、选择第二段、生成摘录；记事本显示结构化来源和“返回原文”；点击后阅读器聚焦到第一章、目标段落可见，控制台无错误。
- 无效来源的纯函数测试覆盖：书籍、版本、章节、段落、偏移缺失或越界。
- 生命周期测试覆盖：来源单独变化的增量保存、复制、回收还原、永久删除、导出恢复和清理。
- `git diff --check` 与目标 diff 审查通过。
- 未运行 lint 或完整构建；未提交、推送或发布。

## 未实现能力

- 没有为已存在的旧摘录推断来源。
- 没有自动联网重新下载已移除的书籍。

# ITER-20260929：音乐续听

- 状态：已完成
- 所属 Spec：`docs/specs/SPEC-20260929-music-resume.md`
- 对应验收项：AC-1 至 AC-6

## 目标与边界

音乐窗口关闭后保留曲目、位置与队列，重新打开时由用户点击续听。修改范围和非目标按 Spec；不实现工作集，不修改阅读器，不增加后台任务或自动播放。

## 实现与验收

1. 音乐资料库增加“上次听到这里”卡片，展示歌曲、歌手和位置；主动点击恢复播放与队列。
2. 复用 IndexedDB 音乐 settings 仓库，播放位置独立于音量和歌单偏好写入，防止彼此覆盖。
3. 保存由现有媒体事件驱动；延迟元数据加载时保留目标位置，切歌取消旧位置，完整结束的歌曲从开头续听。
4. 续听数据接入已有备份、恢复、清理、删除和音频去重流程；删除歌曲与导入后的界面同步最新引用。
5. 更新 Service Worker 版本为 v52；同步已有版本断言，缓存和更新激活策略保持原样。

## 本轮目标

在现有记事本上增加安全的 Markdown 编辑／预览切换，不改变纯文本文件和保存模型。

## 本轮不做

不新增格式、存储、外部图片、原始 HTML 执行、复杂 Markdown 或发布动作。

## 实现—验证记录

### 第 1 轮

- 实现：新增无依赖 Markdown 解析器、懒加载预览组件、编辑／预览控件和桌面／深色／紧凑样式。
- 验证：类型检查发现联合类型判别不够精确；安全链接测试发现被拒绝链接拆成相邻文本节点。相关测试同时触发仓库既有的 `appStyles` 断言，它仍预期 `app/page.tsx` 静态导入 DesktopRoot，与当前仓库的懒加载实现不一致。
- 处理：将联合类型拆为独立判别分支；安全测试改为验证完整文本保留。未修改与本轮无关的旧 `appStyles` 断言。

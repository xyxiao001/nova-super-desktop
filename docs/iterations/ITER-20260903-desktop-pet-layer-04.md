## 本轮目标

让用户可以在设置中创建桌面伙伴，并在桌面完成显示、互动、隐藏、位置持久化和窗口收起。

## 本轮不做

- 不接入应用活动事件；
- 不实现 AI 对话或发送宠物上下文；
- 不注册宠物 Storage Provider 或修改备份；
- 不新增图片、SVG、动画资源包或第三方动画库；
- 不运行 lint 或完整构建。

## 计划修改

- `src/platform/pet/PetRuntime.tsx`：统一加载、更新和持久化宠物状态；
- `src/shell/DesktopPetLayer.tsx`、`desktopPet.css`：CSS 宠物、拖动、互动面板和收起入口；
- `src/shell/DesktopRoot.tsx`：挂载 PetRuntime 与桌面层；
- `src/apps/settings/PetSettings.tsx`：创建、资料、偏好、复位和清除；
- `src/apps/settings/entry.tsx`、`settings.css`：设置分类接入；
- `tests/unit/petIntegration.test.ts`：层级、事件边界和设置接入。

## 实现假设

宠物使用 CSS 绘制，不引入可缓存的大型素材；桌面层默认 `z-index: 10`，低于应用窗口且只有宠物和面板接收指针。位置以归一化坐标保存，拖动结束后一次写入 IndexedDB；最大化窗口或移动端全屏窗口只显示安全区状态入口。

## 本轮目标

在当前记事本窗口内查找全部精确命中，支持上一处／下一处循环，并承接全局搜索的查询与首个选区。

## 本轮不做

不实现替换、正则、模糊搜索、索引持久化、跨文稿导航或后台计算。

## 实现—验证记录

- 扩展 `textSearch`：枚举不重叠、大小写不敏感的匹配范围，并提供循环导航索引纯函数。
- 全局搜索的 notes 定位意图同时携带查询文本；文件名单独命中仍不生成选区。
- 记事本增加查找入口、输入框、计数、上一处、下一处和关闭操作；Enter 下一处、Shift+Enter 上一处，当前窗口内 Command/Ctrl+F 打开查找。
- 文稿切换时清空临时查找状态；预览模式发起定位时先恢复编辑器，再在动画帧中选中并确认请求。

## 验证结果

- `npx tsc --noEmit --incremental false`：通过。
- 相关单测：6 个测试文件、29 项测试全部通过。
- 浏览器隔离来源：全局搜索“摘录”后查找条自动显示 `1 / 1`；把验证文稿改为 3 处命中后，下一处按 `1→2→3→1` 循环，上一处按 `2→1` 返回；关闭查找条后正文与编辑视图保留。
- 最后补测预览切回编辑器再定位的挂载时序，类型与回归测试通过。
- `git diff --check` 通过；本地服务 HTTP 200。
- 未运行 lint 或完整构建；未提交、推送或发布。

## 未实现能力

没有替换、正则、大小写开关、全词匹配、跨文稿结果列表或持久化搜索历史。

# ITER-20260902：资源管理器与文件夹实例化

- 状态：已完成
- 所属 Spec：`docs/specs/SPEC-20260902-window-instances.md`
- 对应验收项：AC-2、AC-3、AC-4、AC-5、AC-6、AC-7、AC-8、AC-10
- 开始日期：2026-09-02
- 完成日期：2026-09-02

## 本轮目标

开放资源管理器显式多窗口和文件夹按资源实例化，让每个资源管理器窗口拥有独立导航状态，并让任务栏按应用分组管理多个窗口。

## 本轮不做

- 不开放记事本、照片查看器或其他应用多实例；
- 不改变文件夹的默认打开方式，桌面双击仍进入资源管理器；
- 不实现资源管理器窗口之间的拖放；
- 不迁移文稿、图片或照片实验室工作对象；
- 不修改桌面文件、备份、资源缓存或 Service Worker。

## 计划修改

- `src/platform/apps/appManifest.ts`：启用资源管理器 `multiple` 和文件夹 `per-resource` 策略；
- `src/platform/windows/windowInstanceState.ts`：补充实例 ID 创建和目标查询；
- `src/platform/windows/WindowRuntime.tsx`：提供新建、打开资源、重定向、聚焦和关闭实例命令；
- `src/platform/workspace/WorkspaceRuntime.tsx`：移除全局文件夹当前对象，增加打开文件夹窗口命令；
- `src/shell/DesktopRoot.tsx`：统一实例创建策略、资源目标和文件生命周期；
- `src/shell/DesktopTaskbar.tsx`、`app/desktop.css`：实现应用分组预览、新建窗口和关闭全部；
- `src/apps/explorer/entry.tsx`：使用实例目标维护独立目录和历史；
- `src/apps/folder/entry.tsx`：按实例目标读取文件夹；
- `tests/unit/`：补充策略、实例命令、架构和文件生命周期测试。

## 实现假设

资源管理器的当前位置使用实例目标，历史、搜索和选择继续保留在组件内部；文件夹窗口使用 `app + folderId` 作为唯一身份，可以消除全局 `activeFolderId` 而不复制桌面文件。
